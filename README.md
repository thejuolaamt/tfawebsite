# The Fine Artist Community website

Built with Next.js and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

- Team: `src/components/Team.tsx`
- Milestones: `src/components/Milestones.tsx`
- Upcoming items: `src/components/Upcoming.tsx`
- Workshop details: `src/components/Workshop.tsx`
- Links: `src/lib/links.ts`
- Photos go in `public/images/`, then set the `image` field on the card.
